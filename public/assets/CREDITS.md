# Visual texture credits

These images are used only as texture references in this educational Three.js project.

- `darkhold-cover-variants.png` — cover collage supplied by the project author/user.
- `references/entrance-relief-user.png` — final entrance relief supplied by the project author/user.
- `pages/spread-manuscript.jpg` — Darkhold manuscript image found via [Pinterest](https://pt.pinterest.com/pin/830210512597771879/).
- `pages/spread-prop.jpg` — open Darkhold prop image found via [Pinterest](https://www.pinterest.com/pin/wandavision-darkhold--296604325472146312/).
- `pages/spread-screen.jpg` — Darkhold frame published by [El Comercio](https://elcomercio.pe/mag/fama/wandavision-donde-esta-wanda-al-final-de-bruja-escarlata-y-vision-series-de-disney-plus-mcu-marvel-nnda-nnlt-noticia/).

The three image spreads are divided into left and right pages in `src/textures.js`, restoring the earlier six-page Darkhold sequence. The four procedural wall-bound guards use a broad, horned tomb-beast silhouette informed by dark-fantasy stone-relief references such as [Resident Evil Village's castle relief](https://www.instant-gaming.com/en/6329-buy-resident-evil-village-pc-game-steam-europe/).
